HOW IT WORKS

작동 원리

사진 한 장이 판정되기까지의 순서입니다. 큰 모델은 그대로 두고, support 예시 20장으로 작은 투영층만 학습했습니다.

판정 순서

  1. 사진 입력고정 카메라 화면 전체 한 장 (예: 1448×1086)입력
  2. 샤프닝 · 384×384 축소Unsharp Mask로 경계를 살짝 강조한 뒤 쌍선형 축소, ImageNet 기준으로 정규화. support 예시에도 같은 처리전처리
  3. 특징 추출ConvNeXtV2-Nano가 사진을 640개 숫자로 요약고정 · 학습 안 함
  4. 투영작은 잔차 투영층(은닉 32)이 포트홀 구분에 맞게 특징을 조정support 예시 20장으로 학습
  5. support 예시와 비교정상 평균, 포트홀 평균까지의 거리를 재서 점수 계산거리 비교
  6. 5개 평균 점수seed가 다른 모델 5개의 점수를 평균해 0 이상이면 포트홀. 판정이 갈리면 함께 표시최종 판정

점수는 이렇게 계산합니다

점수 = (정상 평균까지 거리)² − (포트홀 평균까지 거리)²
점수가 0 이상이면 포트홀 평균에 더 가깝다는 뜻이고, 포트홀로 판정합니다.

점수는 거리 차이이며 확률이 아닙니다. 그림은 실제 640차원 공간을 2차원으로 단순화한 개념도입니다.

해석할 때 주의할 점

  • 평가 500장은 모두 support 사진 한 장(day_dry_01)을 편집해 만든 세트라 장면 다양성이 낮습니다.
  • 백본과 학습 설정은 500장을 보기 전에 정했고, 샤프닝은 모델을 고정한 뒤 오탐 분석을 거쳐 추가했습니다.
  • 단계 간 차이는 구성 요소를 이 순서로 더한 결과이며, 한 요소의 일반적인 효과로 보지 않습니다.
  • 오류는 대부분 정상을 포트홀로 본 경우(FP)이고, 최종 모델이 포트홀을 놓친 경우(FN)는 없었습니다.
  • 판정 점수는 거리 차이이며 확률이 아닙니다.
